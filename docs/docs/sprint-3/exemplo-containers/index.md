# Exemplo de containers para o nó de borda

Esta seção reúne o material que preparei para quem vai containerizar os modelos e rodá-los no Raspberry Pi. Ela parte de dois exemplos que testei no notebook (`x86_64`), sem o Raspberry Pi e sem a câmera. Os termos técnicos estão no [glossário](../../sprint-1/glossario.md).

| Material | O que contém |
| --- | --- |
| [Guia de Docker para quem nunca usou](./guia-docker-para-iniciantes.md) | Conceitos, exercícios, a containerização do projeto passo a passo e o caminho até o Raspberry Pi. |
| [Exemplos de código](./exemplos-de-codigo.md) | Os arquivos dos exemplos `01-contador` e `02-raiar-vision`, com a função de cada um. |

Os arquivos ficam em `src/edge/exemplos-docker/`, e a proposta de arquitetura que eles sustentam está em [Containers no nó de borda](../integracao-containers-no-no-de-borda.md).
